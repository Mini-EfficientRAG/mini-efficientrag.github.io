Mini-EfficientRAG

A Tiny Reproduction of an Efficient & Accurate System

Adapting the official EfficientRAG pipeline to a single-GPU, notebook-based setting on the HotpotQA benchmark. Retrieve fewer passages, achieve higher recall, and generate accurate answers with just one final LLM call.

The Multi-Hop Challenge

Retrieval-augmented generation (RAG) systems often struggle with multi-hop question answering, where a single retrieval step rarely surfaces all necessary evidence. Iterative approaches improve recall but typically rely on repeated LLM calls at each hop, incurring substantial latency and cost.

Mini-EfficientRAG replaces per-hop LLM query rewriting with lightweight learned controllers (a Labeler and a Filter). Designed to be classroom-friendly, this project successfully reproduced the system's core claims using entirely open-source components on a single A100 GPU in Google Colab.

System Architecture

Open-source components optimized for constrained environments

Dense Retriever

Utilizes facebook/contriever-msmarco to index Wikipedia paragraphs from the HotpotQA distractor setting.

Lightweight Controllers

A Labeler and Filter built on top of a frozen DeBERTa-v3 encoder with small classification heads to control retrieval hops.

Answer Generator

Meta-Llama-3-8B-Instruct runs via a local vLLM OpenAI-compatible server for both data synthesis and final generation.

Colab-Friendly Setup

The full pipeline (data synthesis, training, and inference) runs seamlessly end-to-end on a single NVIDIA A100 GPU.

Key Results & Performance

Validating the efficiency trend of EfficientRAG at a smaller scale

📈

Higher Retrieval Recall

Achieves a recall of 79.74%, substantially outperforming the 69.86% of the Direct-R@10 baseline and the 71.21% of the SelfASK baseline.

📉

Fewer Retrieved Chunks

Learned hop control avoids over-fetching distractors, retrieving only 7.29 chunks per question on average compared to SelfAsk's 25.45.

🎯

Better QA Accuracy

Outperforms baselines across all metrics, attaining 52.29 Exact Match (EM), 57.73 token-level F1, and 50.98 Answer Accuracy.

⚡

Single LLM Invocation

Eliminates the need for per-hop generative reasoning. The pipeline uses approximately a single LLM call per question for the final answer.

⏱️

Efficient Training

The Labeler was trained on only ~14% of the synthetic data yet reached 98.1% token-level accuracy and ~90.1% token-level F1.

📚

Reproducible Pipeline

Provides an educational reference for multi-hop RAG research, tracking code patches and infrastructure changes to make the original codebase accessible.

How Mini-EfficientRAG Works

1

Retrieve

Dense retriever fetches the initial top-k passages based on the query.

2

Label & Tag

Labeler predicts token-level useful labels and assigns a <Continue> or <Terminate> chunk tag.

3

Filter & Refine

Filter assigns binary labels to aggregated tokens and constructs the next-hop query.

4

Generate

The generator (LLaMA-3) produces the final answer from the compact context.
